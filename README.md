# 🐙 Darwin's Paradox: Escape from Ufood (Demo)

A fan-made, playable demo inspired by *Darwin's Paradox!*, built with TypeScript and Vite. Help Darwin navigate hazards, outsmart enemies, and make a daring escape from the Ufood facility!

### 🎮 [Play the Live Demo Here](https://darwin-s-paradox-escape-from-ufood.ai.studio)

---

## ✨ Features
- **Stealth & Platforming Action:** Slip past security systems, use environmental cover, and navigate tricky obstacles.
- **Octopus Abilities:** Utilize unique cephalopod mechanics like camouflaging, squeezing through tight spaces, and ink distractions.
- **Fast, Browser-Based Gameplay:** Built with modern web technologies for smooth performance directly in your browser.

---

## 🛠️ Tech Stack
- **Frontend:** TypeScript, HTML5, CSS3
- **Build Tool:** [Vite](https://vitejs.dev/)
